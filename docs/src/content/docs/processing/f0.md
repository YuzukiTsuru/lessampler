---
title: "F0 estimation"
description: "Selectable WORLD, LLSM and RMVPE pitch estimators."
---

F0 is a separate algorithm axis from the vocoder backend. `[f0] estimator` selects one of four estimators; the resolved kind and its parameters are stored in the analysis fingerprint.

| Estimator | Build | Track |
| --- | --- | --- |
| `harvest` | always | WORLD Harvest |
| `dio` | always | WORLD DIO followed by StoneMask |
| `llsm` | `LESSAMPLER_ENABLE_LLSM` | Harvest initial followed by libllsm2's `llsm_refine_f0` |
| `neural` | `LESSAMPLER_ENABLE_NEURAL` | RMVPE ONNX, 16 kHz input, 10 ms frames |
| `auto` | always | follows `[audio_model] backend` |

LLSM has no independent detector: libllsm2 only refines an existing track. The `llsm` estimator therefore runs Harvest first, then `llsm_refine_f0` on the same frame grid. `LlsmBackend` keeps `f0_refine = 0` so the track is never refined twice.

## Configuration

```toml
[f0]
estimator = "auto"          # auto / harvest / dio / llsm / neural
f0_speed = 1                # DIO only
f0_dio_floor = 40.0
f0_harvest_floor = 40.0
f0_ceil = 800.0
f0_cheap_trick_floor = 71.0
f0_allow_range = 0.1

neural_model_path = ""      # RMVPE; separate from [neural] model_path
neural_threads = 0
neural_threshold = 0.03
neural_floor = 40.0
neural_ceil = 1200.0
```

`f0_mode = "DIO" | "HARVEST"` is a deprecated alias for `estimator`; when both keys are present, `estimator` wins.

`auto` resolves as follows:

| Backend | Resolved | Fallback |
| --- | --- | --- |
| `world` | `harvest` | none |
| `llsm` | `llsm` | `harvest` when LLSM is not compiled |
| `neural` | `neural` | `harvest` when neural support or the RMVPE model is missing |

Only `auto` falls back. An explicit unavailable estimator throws a `parameter_error`, so a requested algorithm never silently changes. The fallback logs a warning.

## WORLD estimators

DIO is followed by StoneMask. Harvest is used as-is. The output frame period is `[audio_model] frame_period`; the frame count is

$$
N_f=\left\lfloor\frac{1000N_x}{f_sT_0}\right\rfloor+1.
$$

`f0_speed`, `f0_dio_floor`, and `f0_allow_range` apply to DIO; `f0_harvest_floor` and `f0_ceil` apply to Harvest.

## LLSM estimator

`LlsmF0Estimator` converts the PCM and the Harvest track to libllsm2's `FP_TYPE=float`, calls

```c
llsm_refine_f0(samples, count, fs, f0, frames, frame_period / 1000);
```

and keeps the original value when refinement returns a non-finite or non-positive result. This is a refinement, not a detector: octave errors in the Harvest initial track are not repaired.

## RMVPE estimator

The neural estimator accepts two common ONNX contracts:

- `audio` or `waveform` input -> `salience` `[1,T,360]` (or `[1,360,T]`). The peak bin is decoded with

$$
f_0=10\cdot2^{\left(20b+1997.3794084376191\right)/1200}
$$

using a local weighted average around the peak; `neural_threshold` decides voicing.
- `waveform` + `threshold` inputs -> `f0` + `uv`. `f0` is Hz; `uv` marks unvoiced frames.

Input is resampled to 16 kHz with the shared windowed-sinc resampler. The 10 ms track is resampled to `[audio_model] frame_period`: both neighbours voiced uses linear interpolation, both unvoiced stays zero, and a mixed pair uses the nearest frame. RMVPE natively covers about 32-2000 Hz; `neural_floor` and `neural_ceil` clamp the output. The default ceiling is 1200 Hz to match the current WORLD transform average window.

RMVPE weights are not bundled. Set `[f0] neural_model_path` to a local ONNX file. The model is loaded once per process and shared by concurrent voicebank workers; set `neural_threads = 1` when batch modeling many files to avoid oversubscription.

## Factory and targets

`CreateF0Estimator` lives in `VocoderCommon`, below the backends that call it during `Prepare`:

```
VocoderF0Api      F0Track, F0Estimator, shared resampler
VocoderF0World    Harvest / DIO
VocoderF0Llsm     Harvest + llsm_refine_f0   (optional)
VocoderF0Neural   RMVPE + ONNX               (optional)
VocoderCommon     factory, auto resolution, availability
```

`ResolveF0EstimatorConfig` replaces `auto` with a concrete kind before any fingerprint is computed. The resolved kind, neural parameters, and RMVPE path/size/mtime are in the fingerprint; see [Source and cache](source.md).

## Testing

`F0EstimatorTest` covers kind parsing, availability, the auto table, WORLD pitch and determinism, LLSM refinement, track resampling, and fingerprint changes. A real RMVPE run is enabled when `LESSAMPLER_RMVPE_MODEL` points at a model:

```bash
LESSAMPLER_RMVPE_MODEL=/path/to/rmvpe.onnx ctest --preset max-gcc -R F0EstimatorTest --output-on-failure
```

`lessampler --f0 <in.wav> <out.csv>` exports the selected estimator's track as `time_ms,f0_hz`.
