# Quality evaluation

- `evaluate.py`: standardized MOS and objective evaluation CLI.
- `setup_singmos.sh`: optional SingMOS-Pro environment under `build/quality-venv`.
- `fixture.ust`: target used by `QualityEvaluationTest`.

The protocol, JSON schema and CTest options are documented in [docs/src/content/docs/quality.md](../../docs/src/content/docs/quality.md).
